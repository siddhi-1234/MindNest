🌿 MindNest – Digital Mental Health & Wellness Platform for Students

MindNest is a digital mental health and psychological support system designed for students in higher education. The platform provides an accessible, safe, and user-friendly space for emotional support, self-care, counseling, and well-being tracking.
Our goal is to make mental health support affordable, stigma-free, and available 24/7.

🚀 Features

✨ Core Student Features
Firebase Authentication (Login, Register, Anonymous Mode)
Mood Tracker (Daily mood logging with simple UI)
Digital Journal (Write, save, edit, and delete entries)
AI Mental Health Chatbot using Dialogflow
Self-Help Resources
Guided meditation
Relaxation content
YouTube well-being videos
Appointment Booking with campus counselors
Basic real-time chat with counselor

✨ Counselor & Admin Features
Appointment dashboard
Student mood statistics
Simple analytics charts
Manage self-help resources
